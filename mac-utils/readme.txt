these scripts are not part of FoxyRetroMDK program. They are a user utility for macOS (OSX) as a troubleshoot
- uninstall all java jdk versions
- uninstall python 2.7x (any 2.7 python versions)

- download https://support.apple.com/en-us/106384
- bash Java-6-Install.sh
